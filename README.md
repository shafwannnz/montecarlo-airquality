Simulasi Monte Carlo (Prediksi Kualitas Udara)

🔎 Deskripsi

Ini adalah proyek yang dibangun dengan metode Monte Carlo dengan tujuan memprediksi tingkat konsentrasi polutan dan Indeks Standar Pencemar Udara (ISPU) dalam hitungan harian berdasarkan data histori yang ada.

📄 Sumber Data

Jenis Data: Data historis pengamatan kualitas udara harian (air_quality_dataset.csv).

Variabel Data:

🔹 Parameter Polutan & Indeks (PM2.5, PM10, SO2, CO, O3, NO2, dan ISPU)

🔹 Frekuensi kemunculan harian pada setiap kelas interval

🔹 Distribusi probabilitas

🔹 Probabilitas kumulatif

🔹 Interval bilangan acak (00 - 99)

💻 Bahasa Pemrograman & Tools

🔹 Bahasa Pemrograman: Python 3

🔹 Environment: Google Colab / Jupyter Notebook / VS Code

🔹 Library yang Digunakan: pandas, numpy, matplotlib, dan seaborn (untuk pengolahan data, pembangkitan bilangan acak, dan visualisasi grafik)
